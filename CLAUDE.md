## This repo

A Drupal CMS 2.x demo and sandbox, owned by a designer who doesn't write code day to day. Explain changes in plain language and keep README.md current when commands or setup change.

The default site is **Calder University Health**, a fictional academic medical center. `docs/amc-demo-brief.md` is the original brief and `docs/design-system.md` explains the design.

## How it fits together

- **`recipes/amc_demo/`** is a site template (recipe): content types, fields, views, Canvas component config and all sample content (`content/`). `ddev reset` installs it. `ddev save-demo` writes the running site back into it.
- **`web/themes/custom/calder/`** is the theme, generated from the Mercury starter kit (Tailwind 4 and single-directory components).
  - `src/Hook/CalderHooks.php` turns each node into a plain `calder` variable that the templates and components use. Templates never dig through field render arrays.
  - `templates/content/node--<bundle>--full.html.twig` holds the page designs. `node--card` and `node--teaser` render any node as a card or row, and listings and connections use them.
  - Components in `components/`. Ones with `noUi: true` are internal; the rest appear in the Canvas library.
  - Illustrations are generated by `tools/mobiles.py` into `images/mobiles/`.
- **`web/modules/custom/calder_demo/`** holds the logic:
  - `Connections` finds reverse references (who works in a department, which trials a person leads).
  - A presave hook fills `field_keywords`, which Find a Doctor and the trials finder search.
  - `DefaultContentDates` keeps news `created` dates on export and shifts event and news dates on import, relative to `CONTENT_REFERENCE_DATE`.
  - The Person spotlight block for Canvas.
  - Views tweaks: entity-reference dropdown filters, friendlier labels, the accepting-patients checkbox, and the search form rendered in the page.

## Commands

- Rebuild CSS after changing classes in Twig or anything in `src/`: `ddev build-theme`, or `npm run build` in the theme folder.
- Save the site back into the template: `ddev save-demo`. It only picks up new config for the existing Calder content types and views tagged `Calder`. A new content type must be added to `recipes/amc_demo/config` and `recipe.yml` by hand.
- Fresh install: `ddev reset --yes`, or the SQLite recipe below.

## Gotchas (each one cost time)

- Drupal core's unlayered `.hidden` beats Tailwind's layered utilities, so `hidden lg:flex` never shows. Use `flex max-lg:hidden`.
- With PHP assertions on (DDEV's default), every component prop is validated against its schema. Internal components declare nullable types (`[string, "null"]`). Test with `-d zend.assertions=1`.
- A theme may implement each hook only once. `ThemeHooks::preprocessPage()` (from Mercury) calls `CalderHooks::addPageVariables()`.
- Twig `{% block %}` in a template that doesn't extend anything prints where it's defined. Use `{% set x %}...{% endset %}` for reusable chunks.
- Canvas only offers block plugins whose settings schema has `FullyValidatable`.
- The core content exporter skips `created`; `DefaultContentDates` re-enables it for news.
- Tailwind only sees class names spelled out in full. Don't build them with string concatenation; map values to full class strings.
- Drupal CMS's base template adds privacy links to the footer menu. The footer shows childless top-level items as legal links.

## Claude Code cloud sessions

DDEV isn't installed by default and Docker containers can't reach the internet through the session proxy. For a quick preview without DDEV, put an SQLite database in an untracked `web/sites/default/settings.local.php` (the committed settings.php includes it), then:

```sh
export COMPOSER_ALLOW_SUPERUSER=1
composer install
php vendor/drush/drush/drush.php site:install "$PWD/recipes/amc_demo" --account-name=admin --account-pass=admin -y
cd web && php -d zend.assertions=1 -S 127.0.0.1:8888 .ht.router.php
```

Use `vendor/bin/dr` for core console commands such as `content:export` and `generate-theme`. Drush can't drop an SQLite database without the `sqlite3` binary, so delete `web/sites/default/files/.ht.sqlite` before reinstalling.
